## 基本方針

- A4縦・全20ページを第一案とする。マニュアルの用紙は縦、アプリから出力する配置図はA4横と区別する。
- 対象は、導入前の現場メンバー。PCでの操作を前提とする。
- 1〜3ページは導入説明にも使い、4ページ以降は操作の順に読み進める。
- 単独の表紙や章扉は設けず、1ページ目から用途と完成例を見せる。
- 本文は既存下書きを使用するが、初めての人が操作順に追えるよう、品目登録を自動配置のページへ移す。「半」の計算説明と表示設定は同じページへまとめる。
- 実画面の大きさを優先する。20ページに収めるための文字の縮小は行わず、初回の組版で窮屈なページがあれば分割を検討する。
- 図版未制作のため、現時点のページ数・面積配分は案。実画面撮影・PDFの組版検証後に確定する。

## 各ページの共通レイアウト

### 操作ページ（4〜19ページ）の基本形

```text
┌────────────────────────────────┐
│ 章名 ／ 入力 → 配置編集 → 配置図（現在位置）  │
│ ページ見出し                             │
│ このページで行うことを1文で説明             │
├────────────────────────────────┤
│ 実画面の必要箇所・資料・操作前後の図          │
│ ① ② ③ の番号で押す場所と手順を対応         │
│                                        │
├────────────────────────────────┤
│ ① 短い手順   ② 短い手順   ③ 結果の確認     │
│ この操作に関係する注意・補足                │
│                                  ページ番号│
└────────────────────────────────┘
```

- 上部約15%：章・見出し・目的。中央約55〜65%：図版。下部約20〜30%：手順と注意。比率は目安とし、比較図や入力資料の多いページでは調整する。
- 本文は11〜12ptを目安にする。操作の説明は1項目1〜2文。重要な注意は操作の近くに置く。
- 画面全体は位置を覚えるページで使い、操作ページでは必要箇所を切り出して拡大する。
- 図の文字は本文と同程度に読める大きさを目指す。完成配置図の全体縮小図は概要用途とし、読むべき欄を別に拡大する。
- 同じページの操作前後は同じ縮尺・同じ向きにし、変わった場所だけ強調する。
- アプリ内の色を尊重しつつ、番号、輪郭、ロット番号を併記する。白黒印刷でも関係を追えるようにする。
- 「注意」は再配置による破棄など、操作結果に影響する内容に絞る。図・本文で同じ説明を何度も繰り返さない。

## デモの進み方と画面の整合

| 掲載箇所 | 状態 |
|---|---|
| 4〜7ページ | 初回入力。FAX①〜④を入力。画面の進捗に応じた枚数を表示する。 |
| 8〜9ページ | FAX⑤未着。予定個数で仮入力。FAX4枚・仮1件、合計101P。 |
| 10ページ | FAX⑤到着。仕掛品4を27,000個へ修正。FAX5枚・仮0件、合計100P。 |
| 11〜14ページ | 確定した100Pで配置を確認・調整する。 |
| 15〜16ページ | 「荷物をまとめて置けない場合」「使えない場所がある場合」の追加場面。基本例との条件の違いを図の見出しに明記する。入力数量は100Pのまま。 |
| 17〜19ページ | 基本例の最終配置を使う。退避分がある例は部分図として区別し、本文の合計や配置を混在させない。 |

- 3-4の推奨に合わせ、入力の画面図は最初から「半」表示をオンにして撮影する。7ページで設定方法と意味を説明する。
- 「各◯P」表示や移動枚数の例は、実画面で条件が成立することを確認する。成立しない画面に文字を描き足して、アプリがその表示をしたようには見せない。
- 退避・配置不可の説明場面を撮影する際は、元の基本例を保存し、通常例の配置と混同しない。

## HTML版とPDF版

- PDF版は上の20ページを基本とする。
- HTML版は同じ本文・図版を使い、ページ単位の小見出しへ移動できる目次を設ける。画面表示では紙のページ境界による大きな空白は作らない。
- デモ用予定表とFAX5枚は本文中に必要箇所を掲載する。別配布の練習用資料を作る場合は、本編20ページとは別冊にする。現段階では別冊の作成は含めない。

## 次工程で確認すること

1. 5・6ページの資料と入力行、12ページの選択方法、14ページの変更前後が、文字を縮めず収まるか。
2. 15ページの自動退避と手動退避が、別の役割として読み取れるか。
3. 17ページの表記例が実際の自動生成結果と一致するか。
4. PDFを実寸で見たときに画面内の文字が読め、図や注意がページ途中で分断されていないか。

この案は編集上のページ構成であり、HTML実装・ブラウザ印刷の技術設計ではない。実装設計の段階で、印刷・オフライン提供などの技術制約を別途確認する。
