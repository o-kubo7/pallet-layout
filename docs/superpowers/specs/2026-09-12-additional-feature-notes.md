# 追加機能メモ

日付: 2026-09-12

このファイルは、他セッションの実装作業とは別に記録した追加要件メモです。
まだ正式な設計書・実行計画ではありません。実装前に既存仕様との整合性を確認し、必要に応じて設計書へ昇格します。

## 1. 配置編集: 配置不可エリア

- 配置編集で、使用不可エリアまたは配置不可エリアを設定できるようにする。
- 配置不可エリアは、自動配置時に荷物・ロットを置かない領域として扱う。
- 配置編集で配置不可エリアを設定した場合、その場で自動配置を実行したい。
- そのため、配置編集画面に自動配置ボタンを設置する。

## 2. 配置表: 下段項目欄との位置関係の自動修正

- 配置表のメインエリアと下段項目欄との位置関係を自動修正する機能を追加する。
- 対応するエリアに近い下段項目欄へ、ロット情報を表記する。
- 目的は、矢印を長くしすぎず、視認性を向上すること。
- 既存の「PC横・EV横は右詰め」表記ルールと競合する可能性があるため、実装前に優先順位を決める。

検討案:

- 右詰めルールを最優先し、矢印が長くなるケースは許容する。
- 対応エリアへの近さを最優先し、PC横・EV横でも近い欄へ寄せる。
- 原則は右詰めを維持し、矢印長が一定以上になる場合のみ近接欄を優先する。

## 3. 入力画面: ワイドディスプレイ対応

- ワイドディスプレイでは入力画面が横に間延びするため、幅の上限を設ける。
- 画面全体ではなく、入力フォームや入力内容の主要コンテナに `max-width` を設定し、中央寄せする方針が候補。
- 既存のレスポンシブ表示や印刷・配置表表示への影響を確認する。

## 4. 入力画面: タブ表示の視認性改善

- 「入力」などのタブが少し分かりづらいため、タブボタンだと分かる見た目に修正する。
- 選択中・未選択・hover の差が分かるようにする。
- 境界線、背景色、下線、角丸などを使い、切り替え操作であることを明確にする。
