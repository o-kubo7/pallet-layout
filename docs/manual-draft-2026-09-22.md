# パレット配置アプリ 操作マニュアル

本文下書き・2026年9月22日

対象：初めてアプリを使う現場メンバー。PCのマウス・キーボードで操作します。

> 制作メモ：［図］は、今後挿入する図版の指示です。完成版では実画面または模式図に置き換えます。デモの品名・数量は説明用です。画面撮影と操作の通し確認は未実施です。

## 1. このアプリでできること

### 発送伝票から、配布用の配置図を作る

翌日搬入される荷物の発送伝票を見て、品目・ロット番号・個数を入力すると、パレット数を計算し、配置案を作成できます。配置を調整したら、チームに配布する配置図を印刷します。

荷物やロットが多い日に時間がかかる、ロットごとの集計と配置図の記入を省力化します。自動配置の結果は、現場で使いやすい配置になっているか確認し、必要に応じて直します。

［図1：完成した配置図。搬入日、品名、ロット、パレット数、置き場所、追記欄を示す。］

| 今までの作業 | アプリを使う作業 |
|---|---|
| 伝票と予定表を確認する | 伝票の内容を入力し、予定表でSNPを確認する |
| パレット数を計算し、ロットごとに集計する | 入力した内容からアプリが計算・集計する |
| 配置を考えて用紙に記入する | 自動配置を確認・調整し、配置図を作る |
| 人数分をコピーして配る | 配置図を印刷し、人数分をコピーして配る |

### 作業で使う3つのタブ

**入力 → 配置編集 → 配置図** の順に進めます。

| タブ | ここで行うこと |
|---|---|
| 入力 | 伝票を入力して、自動配置を作ります。 |
| 配置編集 | 配置を確認し、荷物を移動して整えます。 |
| 配置図 | 配布する図を確認し、必要なら表記を整えて印刷します。 |

「設定」では品目マスタや表示などを変更できます。毎日の作業では、まず上の3つのタブを使います。

［図2：PC画面のタブを拡大。3つのタブを矢印で結び、それぞれの役割を短く添える。］

## 2. 配置を考える基本

### 品目ごと、その中でロットごとにまとめる

作業者は、品目・ロットごとにパレット側面のバーコードと積載数を登録し、事務方に入庫設定を依頼します。入庫設定の完了は品目ごとなので、まず同じ品目を近くにまとめます。その中で、同じロットのパレットを隣接させると、登録時の取り違えを防ぎやすくなります。

### 充填品を倉庫内へ優先する

製品は入庫前に検査があることが多く、入庫設定が遅くなりがちです。そのため、アプリでは充填品を優先して、入庫口に近い倉庫内に配置します。

### エリアと列を単位に配置を考える

「メイン」「軒下①」などのエリアの中で、基本的には列を単位に置き場所を考えます。配置編集の1マスは、パレット1枚分の場所です。

パレット数の多い荷物を入庫口に近づけることを基本に、品目・ロットのまとまりと列への収まりを確認します。隣接する品目の境目では、異なる品目を同じ列に置いて空きを活用する場合もあります。

自動配置だけで、すべての品目が合計パレット数の多い順になるわけではありません。配置を見て、収まりやまとまりが分かりやすくなるよう調整します。

［図3：エリア → 列 → パレットの拡大図。同じ品目の中に複数ロットがまとまっている例。色だけに頼らず品名・ロット番号を添える。］

### 「半」も1枚分の場所を使う

端数のあるパレットを、現場では「半」と呼びます。「半」は、必ずしも積載数がちょうど半分という意味ではありません。

例えばSNPが500、個数が2,750なら、満載5枚と端数1枚です。置き場所は合わせて6枚分必要なので、配置に使うパレット数は切り上げて数えます。

同じ品目・同じロットが複数の伝票にある場合も、伝票の各行で切り上げてから合計します。

［図4：500個入りパレット×5枚＋250個入りパレット×1枚＝6P。端数の1枚に「半」を添える。］

## 3. 「入力」—その日の荷物を入力する

### 3-1. 前回の入力をクリアする

「入力」タブで「あさ／ひる」を確認し、「入力をクリア」を押します。確認画面の内容を読んで実行します。

クリアされるのは選択している側のデータです。反対側と品目マスタは残ります。朝・昼の両方を新しく作る日は、それぞれを確認してクリアします。初回で入力がなければ、この操作は不要です。

### 3-2. 搬入日と「あさ／ひる」を確認する

搬入日を指定し、これから作る「あさ」または「ひる」を選びます。朝と昼は、別々に入力・配置・印刷します。搬入日は共通です。

本書では、朝搬入分を例に進めます。

［図5：入力画面上部。「あさ／ひる」「入力をクリア」「搬入日」の位置を示す。］

### 3-3. FAX伝票を入力する

1. 「＋ FAX伝票を追加」を押します。
2. 種別を「製品」または「充填品」から選びます。
3. FAXを見て、品名・ロット・個数を入力します。
4. 予定表でSNPを確認し、入力します。
5. 同じ伝票に別の品目やロットがあれば、その伝票内の「＋ 品目を追加」で行を増やします。
6. 次のFAXは「＋ FAX伝票を追加」で別の伝票として入力します。

製品は一品目一伝票、充填品は一枚に複数品目・ロットを含む例で練習します。種別も配置に関わるため、品名だけでなく種別を確認してください。

入力画面上部の「FAX伝票 ◯枚」を、手元の実物のFAX枚数と照合します。実物1枚に対してアプリでも1伝票として入力することで、入力漏れを見つけやすくなります。仮伝票は「仮 ◯件」と別に表示されます。

［図6：FAX①とPC入力画面を左右に並べる。品名・ロット・個数を同じ番号で結ぶ。SNPは予定表から別の矢印で示す。］

［図7：複数の品目・ロットを含むFAX③と、「＋ 品目を追加」で3行にした入力画面。画面上部のFAX枚数と手元の伝票枚数を照合する図も添える。］

### 3-4. SNPとパレット数を確認する

入力するとパレット数が計算されます。「設定」→「表示設定」→「端数の書き方」で、入力画面の「半」表記をオン・オフにできます。

**配置編集に進む前の入力確認では、満載と端数を見分けやすい「半」表記を推奨します。** 「入力画面での端数を『半』で表示」をオンにしてください。

例えば製品2は、SNP 500・個数2,750なら、オンでは「5P 半」、オフでは「6P」と表示されます。どちらも満載5枚と端数1枚で、配置に必要な場所は6枚分です。表示を切り替えても、必要なパレット枚数は変わりません。

同じ品目でもSNPが異なる場合があります。自動入力された場合も、必ず予定表のSNPと照合してください。数が合わないときは、個数とSNPの両方を確認します。

［図7補足：「半」表示の設定箇所と、同じ入力の「5P 半」「6P」を対比。以後の入力画面の図は「半」表示オンで統一する。］

### 3-5. 品目を登録して、次回からの入力に使う

使い始めは、品名とSNPを一から入力します。「自動配置を作成」を押した際に、未登録の品目があると登録確認が表示されます。品名・SNPが正しいことを確認して登録します。

登録した品目は、次回から品名候補やSNPの補完に使えます。登録を見送っても配置図は作成できます。

［図8：未登録品目の確認画面と、次回に品名候補を選ぶ場面。「補完後もSNPを照合」を添える。］

### 3-6. FAXが届いていない荷物を仮伝票で入力する

FAXが未着でも、予定表にある荷物を含めて配置を考えられます。「＋ 仮伝票を追加」を押し、予定表の内容を入力します。

仮伝票はアプリ上の入力枠で、実物の発送伝票ではありません。個数は予定値です。後から届くFAXと異なることがあります。

本書では、FAX①〜④は到着済み、FAX⑤は未着として入力します。この段階では、予定表の数字を使った合計は101Pになります。

画面上部は「FAX伝票 4枚 ／ 仮 1件」です。手元のFAX4枚と照合し、未着の1件は仮伝票として区別します。

［図9：予定表のFAX⑤相当の2行 → 「FAX未着」と表示された仮伝票。架空の紙の仮伝票は描かない。］

### 3-7. 自動配置を作成する

入力内容とFAX枚数を確認し、「▶ 自動配置を作成」を押します。入力の不備が示された場合は、該当箇所を修正してから実行します。

配置ができたら「配置編集」で結果を確認します。使えない場所をあらかじめ避けたい場合は、4-8の「配置不可エリア」を使います。

### 3-8. 後からFAXが届いたら照合・修正する

1. 対応する仮伝票を開き、届いたFAXと品名・ロット・個数を照合します。
2. 個数などに違いがあれば修正します。SNPも予定表と照合します。
3. 「FAX受領済みにする」を押します。同じ荷物を別のFAX伝票として重複入力しないようにします。
4. 数量など配置に関わる入力を変更したら、自動配置を作り直し、配置を確認します。

今回の例では、受領済みにすると「FAX伝票 5枚 ／ 仮 0件」になります。届いたFAX⑤を含む実物5枚と照合します。

| 仕掛品4／444-4444 | 予定表による仮入力 | FAX到着後 |
|---|---:|---:|
| 個数 | 28,500 | 27,000 |
| SNP（予定表で確認） | 2,000 | 2,000 |
| パレット数 | 15P | 14P |
| 全荷物の合計 | 101P | 100P |

**手動で調整した後に自動配置をやり直すと、その手動調整は破棄されます。** 確認画面の内容を読んでから実行し、再配置後は配置図の表記も確認してください。

［図10：予定28,500 → 実際27,000の差分、修正する個数欄、受領済みボタンを順に示す。以後は100Pの確定データを使用。］

## 4. 「配置編集」—配置を確認して整える

### 4-1. 配置を確認する

品目がまとまっているか、その中で同じロットが近くに置かれているかを確認します。列の空きとパレット数を見て、必要なら配置を整えます。

［図11：100Pの自動配置画面。エリア名、ロット、通路、退避スペースを示す。調整する箇所は実際の配置結果を確認して選ぶ。］

### 4-2. パレットを選択する

**パレットの選択・移動はロットごとに行います。異なるロットを同時には選択できません。**

| 操作 | 選び方 |
|---|---|
| 1枚を選ぶ | パレットをクリックします。 |
| 複数枚を選ぶ | Shiftキーを押しながら、同じロットのパレットをクリックします。 |
| 範囲で選ぶ | 荷物のない位置からドラッグし、矩形で同じロットのパレットを囲みます。 |
| 1枚を選択から外す | 選択済みのパレットをShift＋クリックします。 |
| 選択をすべて解除する | 配置編集の荷物のない位置をクリックします。 |

通常のクリックは、複数選択を追加する操作ではありません。複数枚を選ぶときはShift＋クリックか矩形選択を使います。

［図12：単一選択、Shift＋クリック、矩形選択と、荷物のない位置をクリックして選択解除する操作。選択色に加えて輪郭と枚数を示す。］

### 4-3. 移動先の列へドラッグする

選択したパレットを、移動先の列へドラッグします。その列の空きに入る枚数だけ移動します。

例えば5枚を選択しても、移動先の空きが3枚分なら移動するのは3枚です。**移動後は選択が解除されます。** 残りを動かすときは、もう一度選択して次の列へ移動します。

［図13：5枚選択 → 空き3枚の列へ移動 → 3枚移動・2枚残る。最後のコマで選択解除も示す。実画面では同じ条件を作って撮影。］

### 4-4. 同じロットを近くにまとめる

離れている同じロットのパレットを、近くの列へ移動します。ロットのまとまりが見分けやすくなったか、移動後に確認します。

### 4-5. 列の空きを使う

品目のまとまりを保ちながら、列内の空きへ別のロットを移動します。隣接する品目同士でも、境目の列を共用することで省スペースになる場合があります。

［図14：同一ロットを近づける例と、列の空きを活用する例。それぞれ変更前後を同じ縮尺で表示。］

### 4-6. 退避スペースを確認・活用する

**自動配置で置き場が見つからなかった荷物は、退避スペースへ自動的に配置されます。** 自動配置の後は、通常の置き場所だけでなく退避スペースも確認してください。

配置を組み替える際は、退避スペースを一時的な移動先として使えます。同じロットのパレット全体を選び、まとめて移動できます。

荷物量が多い日や使えない場所がある日など、まとめて置けない荷物を残しておくこともあります。退避中の荷物は配置図の表に記載し、存在をチームで共有します。

当日は、先に搬入された荷物のうち入庫できるものから入庫します。スペースが確保できたら、現場判断で倉庫内・外の置き場所を決めます。

退避スペースから通常の列へ戻す場合も、列の空きと移動できる枚数を確認します。

［図15：自動配置で退避スペースに入った荷物と、印刷する配置図上の対応する欄を結ぶ。配置の組み替えで手動移動する例は別コマにする。］

### 4-7. 操作を元に戻す・やり直す

選択や移動を戻したい場合は「元に戻す」、戻した操作をやり直す場合は「やり直す」を使います。入力変更や再配置による破棄を取り消すための機能ではありません。

［図16：PC画面の戻す・やり直すボタン。アイコンだけの表示と文字付き表示の対応を小さく示す。］

### 4-8. 必要に応じて配置不可エリアを設定する

すでに荷物がある場所など、自動配置で使いたくない場所が分かっている場合に使います。必須の操作ではありません。

「配置不可エリアを設定」を押し、使えないマスを指定して「自動配置を実行」します。設定した場所を避けた結果を確認します。手動調整後にやり直す場合は、表示される確認を読んで実行してください。

［図17：使えないマスの指定 → その場所を避けた配置。操作の詳しいクリック手順は実画面確認時に確定。］

## 5. 「配置図」—見やすく仕上げて配布する

### 5-1. 配置図を確認する

「配置図」タブを開きます。搬入日と「あさ／ひる」、品名・ロット・パレット数、置き場所を確認します。画面が小さく感じる場合は表示倍率を変更します。

### 5-2. 複数ロットの自動表記を読む

同じ品目の複数ロットは、条件に応じて一つの欄にまとまります。まとまった欄のパレット数表記が同じなら「各10P」など、異なる場合は「9P/7P」などと表示されます。端数がある場合は「半」の表記も確認します。

「各◯P」は、ロットそれぞれのパレット数です。例えば2ロットが「各10P」なら、合計は20Pです。すべての同一品目が、配置場所にかかわらず一つの欄になるわけではありません。

［図18：自動生成された複数ロット欄。「各◯P」と、数量が異なる場合の対比。仕掛品2は各10Pの候補だが、実際の掲載条件を確認して撮影。］

### 5-3. 必要に応じて表記を整える

自動表記だけでは作業者が読み取りにくい場合は、「✏ テキスト編集」を使います。例えば、注釈へ「（計20P）」と補足すれば、複数ロットの合計を把握しやすくなります。

この機能は印刷する表記を整えるものです。荷物の個数や配置を変えたい場合は、入力や配置編集で修正します。

表記の編集は、配置を整えた後に行います。後から配置が変わるとテキスト編集が破棄される場合があるため、配置変更後はもう一度確認します。

［図19：自動表記のままの欄 → 注釈に合計を追加した欄。PCでの編集開始・確定の操作を実画面で示す。］

### 5-4. 印刷前に確認する

- 搬入日と「あさ／ひる」は合っていますか。
- FAXと入力内容を照合しましたか。未着分は予定値として確認できていますか。
- 入力画面上部のFAX枚数は、手元の実物の枚数と合っていますか。
- 品目・ロット・パレット数は合っていますか。今回の確定デモは合計100Pです。
- 品目・ロットのまとまりと置き場所は分かりやすくなっていますか。
- 退避スペースの荷物も記載されていますか。
- テキスト編集後の数量・注釈に誤りはありませんか。

### 5-5. A4横で印刷して配布する

「🖨 印刷」を押し、印刷画面で用紙がA4、向きが横になっていることを確認します。プレビューで文字や図の欠けがないことを確認して印刷します。

印刷した配置図をチーム人数分コピーし、配布します。昼搬入分も、昼のデータに切り替えて同じ流れで作成・印刷します。

［図20：印刷ボタン → A4横の印刷プレビュー → コピー・配布。印刷画面は撮影したブラウザの表示例として示す。］

## 6. 補足—保存と設定

### データは使用しているブラウザに保存される

入力や配置などは、使用しているブラウザに保存されます。別のPCやブラウザへ自動で共有されるわけではありません。ブラウザのサイトデータを削除すると、保存内容も失われます。

### 入力を変えた後は配置を確認する

個数など配置に関わる入力を変えた場合は、以前の配置をそのまま使わず、再配置と確認を行います。手動調整やテキスト編集を済ませた後の変更では、やり直しが必要になる点に注意します。

### 「設定」で変更できること

| 項目 | 主な内容 |
|---|---|
| 品目マスタ | 品名とSNPの登録・修正、JSON保存・読込 |
| 配置マス | 配置に使うスペースの設定 |
| 表示設定 | 配置図の文字、端数の表記、複数ロットのまとめ表示など |

品目マスタのJSON保存は、品名とSNPのリストの保存です。伝票や配置など、作業データ全体のバックアップではありません。

### 制作時の確認項目

- 実画面撮影はデモ専用のブラウザ環境で行い、普段の保存データを使わない。
- 原稿の順序で実際にクリック・ドラッグし、入力から印刷まで通す。
- 予定値101P → FAX照合後100Pになることを確認する。
- 自動配置後の具体的な置き場所は未確定。実際の結果を見て移動例と図の対象を選ぶ。
- 「各◯P」表示は掲載場所・まとめ条件にも依存する。例が実画面で成立することを確認する。
- 退避や配置不可エリアの例は、通常例とは場面を分けて撮影し、100Pの入力内容は維持する。
- 仮伝票から受領済みに変えた際の画面上の伝票番号を確認し、説明用FAX番号と混同させない。
- テキスト編集の確定方法、配置不可マスの指定方法、印刷設定の見え方は実画面で確認する。
- HTML・PDFの完成版では、この制作メモと制作時の確認項目を利用者向け本文から外す。
